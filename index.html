MASTER’S THESIS · ITCL TECHNOLOGY CENTRE · 2026

Local agentic AI for business-feature extraction

  • Ran controlled experiments on five information-extraction systems using real business-card data (693 field-level instances).
  • Built an evaluation framework: correct / wrong / missing / invented labels, field-level accuracy, BERTScore, invalid-output rate and reliability analysis.
