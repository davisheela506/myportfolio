Master's thesis · ITCL Technology Centre

Evaluation of LLM-based agentic architectures

Explored emergent capabilities in agentic frameworks, including memory, planning, tool use, OpenClaw integration, and local model evaluation on edge hardware.

  • Built a business-card information extraction benchmark using 33 cards evaluated across three runs each.
  • Examined field-level correctness, missing and invented information, output validity, and response time across local model pipelines.
  • Worked with an NVIDIA Jetson AGX Orin 64GB platform and local inference workflows.
